# Our Galaxy · 私人星图

一个以“回忆是星星，时间是穿过银河的方向”为概念的纪念日网页。

## 当前开发进度

目前完成 **阶段 1–3 与空白十年制作模式**：

- 原生 HTML / CSS / JavaScript 工程骨架
- 响应式首屏视觉系统
- Canvas 动态银河背景
- 极慢但可感知的银河旋转、近景星光呼吸和轻微指针视差
- 移动端粒子降级和 `prefers-reduced-motion` 支持
- 2022–2025 与未来星域，共 23 颗示例故事星
- 每年独立生成一片包含环境星尘与多颗故事星的年度星空
- 滚轮、键盘和手机滑动按“年份”切换完整星域
- 航行模式与自由星图模式
- 故事星点击和轻量回忆信号预览
- 完整回忆卡片与多照片画廊
- 每段回忆最多上传 8 张照片，自动压缩为适合网页的尺寸
- IndexedDB 本地持久化、封面设置与照片删除
- 十片关系年度星域，初始没有任何预设故事星
- 双击左上角 `OUR GALAXY` 进入制作模式
- 用户确认后才生成故事星，并使用 localStorage 保存故事内容

后续阶段：

1. 移动端交互、无障碍、性能优化与最终验收

## 运行方法

### 方法一：直接双击打开（推荐）

进入 `D:\AI_Project\Galaxy`，双击 `index.html` 即可。当前版本不需要先启动 PowerShell 或本地服务器。

### 方法二：使用 Python 本地服务器（仅用于开发调试）

在项目目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765
```

### 方法三：使用 VS Code Live Server

安装 Live Server 扩展，右键 `index.html`，选择 **Open with Live Server**。

## 阶段 1 的关键实现

- `GalaxyRenderer` 将背景星、星云、银河星尘拆分成不同绘制层。
- 银河粒子按四条螺旋臂生成，而不是完全随机，因此远看具有银河结构。
- 星云先绘制到离屏 Canvas，动画时直接复用，减少每帧渐变计算。
- 动画约限制为 45 FPS，并根据屏幕宽度调整粒子量。
- `devicePixelRatio` 最高限制为 1.6，避免高分屏手机产生过大的画布。
- 用户启用“减少动态效果”时只绘制静态画面。

## 阶段 2 的关键实现

- `stories.js` 保存故事内容及星图位置，后续替换真实回忆无需改交互代码。
- 年份是时间航行的一级单位；进入某一年时，该年全部故事星会同时展开。
- 环境星不承载故事，只负责组成丰满星群；较明亮的故事星可以点击。
- “航行”模式按年份推进，“星图”模式将五片年度星域同时展开成完整银河。
- 桌面支持滚轮和方向键，手机支持上下滑动。

## 阶段 3 的照片保存说明

- 点击任意故事星，在回忆卡片中选择“添加照片”。
- 每段回忆最多 8 张，超大照片会在浏览器内缩放并压缩。
- 照片保存在当前浏览器的 IndexedDB 中，关闭网页后仍会保留。
- 浏览器“清除网站数据”会删除这些本地照片。
- 本地照片不会自动出现在另一台电脑或手机上；正式部署前需要导出为网站资源。

## 制作模式

1. 双击左上角 `OUR GALAXY`。
2. 选择关系的第几年。
3. 亲自填写日期、星星名称和回忆内容。
4. 点击“确认添加这颗星”。

初始十年星图只有生成的银河与环境星，不包含任何预设故事星。系统不会为故事星自动起名。
